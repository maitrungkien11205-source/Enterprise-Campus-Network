# Enterprise Campus Network Design & Simulation

## Overview
This project demonstrates the design and simulation of an enterprise campus network using Cisco networking technologies.

## Network Topology
[Network Topology](image.png)

## Technologies Implemented
- VLAN & 802.1Q Trunking
- STP / RSTP
- EtherChannel (LACP)
- OSPF Dynamic Routing
- NAT / PAT
- Access Control Lists (ACL)
- DHCP

## Tools
- Cisco IOS
- PNET

## Objectives
- Implement enterprise network segmentation.
- Configure dynamic routing and network redundancy.
- Provide simulated Internet connectivity.
- Implement basic network access control.
- Verify and troubleshoot enterprise network connectivity.

## Project Status
Configuration completed. Test documentation in progress.
